# Development roadmap

1. Reproduce the clean-install failure and capture existing tests and classification output.
2. Introduce contextual topic classification and consequence scoring with reproducible benchmarks.
3. Index recent related reports incrementally, with publisher attribution and chronological evidence.
4. Integrate grounded briefings, broader search and device-local saved discovery into the current newsroom.
5. Consolidate scheduled refresh, bound external work, add CI and exercise the normal product flows.
6. Review false positives, uncertainty and mobile behavior. Record verification scope and open a draft PR.
