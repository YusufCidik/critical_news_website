# Product gap analysis

| Priority | Observed gap | Product response |
| --- | --- | --- |
| First | Incidental AI mentions and publisher labels override editorial subject. | Require contextual evidence and expose classification provenance. |
| First | “Critical” primarily reflects vocabulary and category. | Separate category importance, broad consequences, confidence and relevance. |
| First | Duplicate headlines can hide publisher coverage, while paraphrases occupy separate cards. | Canonicalize article identities and surface conservative related coverage. |
| First | Article briefing output can contain unsupported claims despite schema validity. | Validate selections against publisher evidence and preserve the original reports. |
| Next | Search checks loaded pages only, and saved stories lack a discovery view. | Search the filtered server snapshot and add a device-local saved view. |
| Next | A separate unused cron consumes model quota and can fail to write in serverless execution. | Refresh the shared RSS path and require a configured secret. |
| Later | Events, source health and history vanish on cold starts. | Measure clustering and retention needs before selecting durable storage. |
